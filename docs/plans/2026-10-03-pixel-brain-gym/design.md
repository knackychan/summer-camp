# Pixel Brain Gym

Scope authorized by Papa's request on 2026-10-03: extend the pixel world style to every Brain Gym exercise, improve touch response, replace Number Cruncher and retire City Drive. This supersedes the scanner direction in the proposed July Brain Gym visual plan. Papa subsequently approved the six suggestions below and requested memory games; implementation is tracked in [the eight-exercise plan](02-six-exercises.md).

## Presentation and interaction

- Shared lilac handheld shell, cream arithmetic paper, dark pixel edges, readable number tiles, mint selections, and yellow targets.
- The exercise occupies the available screen. Game switching stays in a compact scrolling strip; progress and time appear once inside the round.
- Counting objects can be marked with a tap. Calculations support numeric keys, Backspace and Enter. Color Words keeps its bilingual instruction beside the prompt.
- Change Maker opens immediately; coins react to a tap and can be taken back from the tray. Duplicate submissions are ignored. Correct feedback is brief; study time and corrective explanations retain their existing durations.
- Motion uses the existing round scheduler and respects reduced motion. English and Taiwan Traditional Chinese, offline play, scoring and daily completion remain supported.

## Game changes

**Number Bonds / 數字好朋友** replaces Number Cruncher. Tap two tiles that sum to the target. Beginner boards have four tiles and counting dots; middle boards have six tiles; hard boards have eight. There is exactly one valid pair per board. Tapping the first tile again deselects it. The existing `crunch` ID preserves completion/history; old counting-field saves restart while new bonds saves resume.

**City Drive** is removed from the catalog and launch routes pending a different design. Historical source and previously earned scores are retained.

## Original suggestions — approved in the follow-up

| Subject | Exercise | Interaction and learning progression |
| --- | --- | --- |
| Math | Fraction Picnic / 分數野餐 | Tap slices to share a meal equally; progress from halves and quarters to equivalent fractions. |
| Math | Balance Lab / 天平實驗室 | Place numbered blocks on a scale; progress from equal quantities to a missing addend and simple equations. |
| Science | Circuit Builder / 電路小工匠 | Tap wire tiles and switches to complete a loop, then predict whether the bulb lights. Start with one switch; add conductors and insulators. |
| Science | Science Sorter / 科學分類站 | Tap a specimen and a category. Sort materials or living things using one visible property, then explain the clue. |
| Language | Sentence Train / 句子小火車 | Tap word carriages into order and hear the sentence. Start with picture-supported three-word phrases; add punctuation and longer sentences. |
| Language | Sound Match / 聲音配對 | Hear a word, then tap its picture or initial sound. Progress to English spelling, French vocabulary, or 注音 syllables using existing language pools. |

The final implementations and the next unimplemented proposals are recorded in [the eight-exercise plan](02-six-exercises.md). Sound Match ships English and Bopomofo rather than the optional French extension. Circuit Builder focuses on switches and conductor selection. These are original game concepts, not claims about measured educational effectiveness.
