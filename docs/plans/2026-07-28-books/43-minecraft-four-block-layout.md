# The Evolution of Minecraft - Four-Block Layout
# Minecraft 的演化史 - 四格版面

**Purpose:** layout-ready bilingual Markdown for a Minecraft book that uses four side-by-side page blocks per spread instead of the existing double-page reader idea.  
**Companion manuscript:** `42-minecraft-evolution-book.md`  
**Suggested reader shape:** one spread = four equal blocks in a 2x2 grid on tablet portrait, 4 columns on wide screens, 1 column on narrow phones.

---

## Layout Contract

Each spread is four mini-pages arranged side by side. The four pages do not need fixed roles or matching topics. They are simply four balanced reading blocks that can carry the story forward in a pleasing rhythm.

Use the spread like this:

1. **Page 1:** start the moment or idea.
2. **Page 2:** continue with a concrete detail.
3. **Page 3:** add another angle, example, or consequence.
4. **Page 4:** land the spread with a memorable closing thought.

每個跨頁由四個並排的小頁面組成。四頁不需要固定角色，也不必各自對應特定主題。它們只是四個平衡的閱讀區塊，用漂亮的節奏把故事往前推進。

建議使用方式：

1. **第 1 頁：** 開始一個時刻或想法。
2. **第 2 頁：** 接續一個具體細節。
3. **第 3 頁：** 加入另一個角度、例子或後果。
4. **第 4 頁：** 用容易記住的收尾想法完成這個跨頁。
