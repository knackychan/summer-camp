Minecraft announces game drops
------------------------------

A "Minecraft game drop" is a themed, smaller content update that releases between major annual updates. Instead of one large update per year, Mojang now releases multiple "drops" throughout the year to provide content more frequently, keeping the game fresh and interesting. These drops vary in size and focus on a specific theme, adding things like new mob variants, decorative blocks, and items.

[Learn more about game drops](https://www.minecraft.net/article/the-future-of-minecrafts-development)

Frequently Asked Questions
--------------------------

### When does Minecraft release new updates?

We release new features into Minecraft several times a year for free in what we call game drops.  Simply update your game to the latest version to play them!

### What are Minecraft’s game drops?

Game drops are more frequent releases of new Minecraft content. Instead of providing one free update during the summer, as we’ve done in the past, we’ll now be releasing a number of free game drops throughout the year.

### When did Minecraft introduce game drops?

Game drops began in 2023 with Bats and Pots – and since then have continued with The Garden Awakens, Chase the Skies, Mounts of Mayhem, and more! Game drops include content such as new biomes, mobs, items, weapons, music, blocks, and other features.

### What is Vibrant Visuals?

[**Vibrant Visuals**](https://www.minecraft.net/vibrant-visuals-update) is Minecraft’s biggest visual refresh to date. Released in June 2025 for Bedrock Edition, we are currently working on bringing Vibrant Visuals to Minecraft: Java Edition.

### Do Minecraft updates and game drops release at the same time for Java and Bedrock Edition?

Yes, game drops and game updates release on the same day for both Bedrock and Java Edition. The exception is Vibrant Visuals, which released for Bedrock Edition in June 2025. We are working to bring Vibrant Visuals fully to Java Edition in the future.
