# Slice 06 review: card-room hints (approved by Papa 2026-10-06, after playing them)

Each quest: gentle (on the quest card), strong (after the first stuck moment), near (lead-in to the peek of the real solution). No hit counts anywhere: fights use Repeat + "if enemy", which stops when the enemy is gone, whatever blade the kid has. Every fight strategy suggested here was run in the model with damage 1 and 2 and wins.
