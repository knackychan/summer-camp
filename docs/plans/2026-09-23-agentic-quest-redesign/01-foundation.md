# Slice 01 — Quest shell foundation

## Goal

Make Quests the default child experience while retaining all legacy functionality behind secondary navigation.

## Includes

- new quest data + engine + progress modules;
- local Summer agent facade;
- Android-oriented platform bridge;
- new quest home UI;
- Adventure launcher;
- Today retained as secondary view;
- service worker update.

## DONE WHEN

- selecting a kid opens Quests, not My Day;
- the child can choose a preference and receive currently valid quest cards;
- time-gated quests appear only in their configured windows;
- completed quests disappear for the current day;
- a guided household/self-care quest can be started and completed;
- a completed rewardable quest calls the existing synced star ledger once only;
- Brain Sprint and Play quests can route into the existing game system;
- all new child-facing text is EN + Traditional Chinese;
- all new functionality still works without network or LLM access.
